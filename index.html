Modding Knowledge

Beginner

The Root Folder

Install Skyrim outside of Program Files to avoid Windows permission errors. Use a folder like C:\Games\Skyrim.

Intermediate

SSEEdit Cleaning

Clean your Master files! Removing "Identical to Master" records can prevent subtle crashes in heavily modded games.

Advanced

MCO & Animation

When using ADXP/MCO, ensure your 'Distar Experience' is installed correctly or your combat will feel like vanilla ice-skating.

The Nolvus Guide

Nolvus transforms Skyrim into a modern masterpiece. Follow these 3 golden rules for a successful install:

  • SSD is Mandatory: Never install Nolvus on an HDD; the script lag will be unplayable.
  • Instance Path: Set your installation to C:\Nolvus, not inside your Steam folder.
  • Pagefile: Set a manual Windows Pagefile of 40,000MB to prevent crashes.

🛠️ The Blacksmith's Forge (Troubleshooting)

❌ T-Posing

Run Nemesis/Pandora. This happens when the game has new animations but the behavior files haven't been generated.

❌ Purple Textures

Out of VRAM. Restart the game or use a lower-quality texture preset in your modlist launcher.
